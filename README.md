# 架桥谜题 · Bridges (Hashiwokakero)

一个单文件、离线可玩的架桥谜题（Hashiwokakero）实现。

## 在线玩

（部署到 GitHub Pages 后，把网址填在这里，例如 https://<用户名>.github.io/<仓库名>/）

## 玩法

连接岛屿，使每座岛的桥数等于它的数字。每对岛屿之间最多两座桥，桥不能交叉，所有岛屿必须连成一个整体。

- 从岛屿拖动到同行/同列最近的岛连桥；再次操作变双桥，第三次移除
- 直接点击已有桥也可循环
- 右键擦除单条桥
- 支持提示、检查、撤销/重做、计时、星级评分、每日挑战、历史记录
- 题库按种子生成，保证唯一解；用「用此种子生成」输入种子可还原同一道题
- 隐藏作弊码：在页面依次键入 `hashi` 可直接揭晓答案（作弊局不计成绩）

## 本地使用

直接用浏览器打开 `bridges.html` 即可，无需安装任何依赖。
